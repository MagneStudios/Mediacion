### R-04: Estado `expirado` en casos + TTL de invitaciones

| Cambio | Detalle |
|--------|---------|
| `estado_caso` enum | `ALTER TYPE estado_caso ADD VALUE 'expirado'` |
| `validate_caso_estado_transition()` | Nuevas transiciones: `nuevo → expirado`, `activo → expirado`. Terminal (no salen transiciones) |
| `configuracion` | Seed `invitacion_ttl_horas = 72` (horas de vigencia de invitación) |

**Transiciones de `estado_caso` finales:**
- `nuevo` → `activo`, `terminado`, `expirado`
- `activo` → `en_negociacion`, `terminado`, `vencido`, `expirado`
- `en_negociacion` → `acordado`, `terminado`, `vencido`
- `acordado` → `cerrado`
- Terminales: `cerrado`, `terminado`, `vencido`, `expirado`
