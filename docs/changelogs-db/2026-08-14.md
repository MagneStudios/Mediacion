### validate_rls remoto (pendiente)

- Solo 2 de los 5 usuarios de test existen en remoto (`test_01_setup.sql` crea únicamente parte A/B; mediador/admin/no-miembro y sus fixtures asociados solo existen en la DB local histórica).
- **`authenticated`/`anon` no tienen `USAGE` sobre el schema `public`** en este stack (ACL vacía tras un revoke del bootstrap; `has_schema_privilege = false`). Sin eso, cualquier query sin calificar como rol JWT falla y las policies nunca se evalúan para esos roles. La API hoy funciona porque corre como `postgres` (bypassrls=true).
- Cierre del staging según el escape hatch del runbook: **validación SQL equivalente documentada** (smoke 66/66 + conteos + fixtures + checks puntuales). El 17/17 remoto queda como ticket (requiere migración nueva de grants + fixtures completos).
